How to get your GitHub Token

2Click Generate new token
3Give it a name, e.g. freeedu-admin
4Under Repository access → select Only select repositories → choose freeedu
5Under Permissions → Repository permissions → set Contents to Read and write
6Click Generate token → copy it and paste above
